StationOS Pro is the operating system built for StationPC NAS products and tailored for the DA Series devices. Centered on stability and data security, it combines strong data processing with a diverse application ecosystem. It covers file management, remote access, data protection, multimedia services, containerized apps, and AI-powered services, expanding what a NAS can do.

Key features include:

- System settings and personalization

  The intuitive control panel lets you fine-tune networking, user permissions, hardware, and other settings. Adjust system behavior with flexibility so the NAS fits the needs of individuals or teams.

- Reliable storage management

  Create storage pools with multiple RAID modes and balance capacity, performance, and data security with SSD cache acceleration and drive health checks for a wide range of storage scenarios.

- App management and one-click updates

  The built-in App Center supports installing, uninstalling, and upgrading apps so the system stays current and compatible. Its ecosystem covers both professional tools and entertainment apps, making it easy to manage software for work and media alike.

- Remote access and security

  With remote access services such as StationLinks, you can securely reach your NAS data from anywhere. Built-in dual-layer encryption and fine-grained permission controls safeguard both data transmission and storage.

- AI organization and classification

  Intelligently recognize and organize image files, and use multimodal semantic models to search files quickly. It also includes similar-file and duplicate cleanup, sensitive-data protection, and other tools to help you manage large image libraries efficiently.

- Multimedia services and containerized apps

  Set up a home entertainment center for movies, music, and photo albums, with smooth and stable media playback. It also supports a broad range of Docker-based apps, letting you deploy images quickly and manage their full lifecycle while expanding the device's capabilities.

- Built-in AI assistant and AI apps

  The built-in AI assistant is powered by advanced AI technologies and model management services. It supports semantic file search and intelligent Q&A based on file contents. With a set of AI apps, you can transcribe, translate, and summarize audio files, and intelligently analyze, classify, and annotate large numbers of files, helping you build a smarter personal data center.

<Callout title="Important" type="warn">
The DA400 Air does not support Station AI or some AI app features.
</Callout>
